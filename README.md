# Alpha-Metric Framework: A Chronometric Approach to Cosmology
### Official Research Repository for IJMPD Submission
### Lead Scientist: A.S.M. Imam Hossain (ATPR)

## Overview
This repository contains the numerical source code and algorithmic derivations for the paper: 
"A Chronometric Approach to the Vacuum Energy Catastrophe and Cosmological Tensions via the Alpha-Metric Framework."

## Key Files
- `Alpha_Metric_Calculations_IJMPD.ipynb`: Python code for the 0.0003 Weinberg shift, the 1.7s GW delay, and the 2.5 Gyr galaxy age resolution.
- `main.tex`: The full LaTeX source for the 13-page manuscript.
