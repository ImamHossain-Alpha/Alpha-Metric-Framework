## Overview
This repository contains the numerical source code, algorithmic derivations, and LaTeX manuscript for the paper: 
**"A Chronometric Approach to the Vacuum Energy Catastrophe and Cosmological Tensions via the Alpha-Metric Framework"**

This research introduces the Alpha-Metric framework, interpreting the physical vacuum as a dissipative medium with intrinsic chronometric viscosity (α). By defining the Alpha Property as a source term in the Einstein Field Equations, we provide a mechanical resolution to the Vacuum Energy Catastrophe ($10^{120}$ discrepancy) and modern cosmological tensions.
